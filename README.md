# Movit

> JSP 기반 영화 웹 애플리케이션  

---

## 📅 프로젝트 기간

- **개발 기간**: 2025년 5월 ~ 2025년 6월 (약 5주)
- **참여 인원**: 2인

---

## 🌟 주요 기능

### 1. 🔐 회원 관련 기능
- 회원가입, 로그인, 로그아웃
- 마이페이지: 닉네임/전화번호/이메일 정보 수정
- 관리자 계정 접근 권한 제한 (`AuthFilter` 사용)

### 2. 🎬 영화 목록 및 상세 페이지
- 영화 리스트 출력
- 영화 상세 정보 확인
- 장르, 제목 검색 기능
- 랜덤 영화 추천 기능

### 3. 💳 영화 구매 및 결제
- 영화 구매 요청 시, 쿠키 기반 정보 저장 (`movie_id`, `card_number`, `bank`, `password`)
- 구매 확인 페이지에서 쿠키를 읽어 정보 복원 및 검증
- 구매 완료 시 쿠키 삭제로 보안 처리

### 4. 💬 사용자 리뷰 기능
- 리뷰 작성, 조회, 삭제
- 영화별 평균 평점 집계
- 리뷰 좋아요 기능 (`like_review` 테이블 활용, 중복 방지 로직 구현)

### 5. 📊 관리자 페이지
- 관리자 전용 영화 추가, 삭제 기능
- `web.xml` 필터를 통한 관리자 인증 기능 구현

### 6. 🧾 로그 필터
- 모든 요청 URL, IP, User-Agent, 실행 시간 등을 로그로 DB에 저장 (`LogFilter` 사용)

### 7. 🛠 트러블 슈팅
- 비밀번호 검증 로직에서 JSTL 쿼리 조건 수정 이슈 해결
- 마이페이지에서 form 태그를 개별 처리하여 입력 정보가 동시에 사라지는 문제 해결

---

## 💻 개발 환경 및 기술 스택

- **Frontend**: HTML5, CSS3, JSTL, JSP
- **Backend**: Java Servlet, JSP, JSTL
- **Database**: MySQL (JDBC 연결)
- **서버**: Apache Tomcat 10.x
- **IDE**: Eclipse
- **라이브러리**: com.oreilly.servlet
